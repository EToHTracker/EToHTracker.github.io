# 🎮 EToH Player Tracker Bot

Welcome to the official repository for the **Eternal Towers of Hell (EToH)** live stat tracking application! 

This custom-coded web scanner allows you to type in any valid Roblox username and instantly extract their live accomplishments, tower totals, and hardest completions straight from the Roblox badge database API.

## 🚀 Live Link
Check out the live, running web application right here:
👉 **https://github.io**

## ✨ Features
* 🔍 **Real-Time Search**: Converts text usernames into numerical IDs via the Roblox Users API.
* 🛡️ **Zero Tracking Limits**: Cross-references profiles against an integrated database using a secure proxy gateway.
* 📊 **Difficulty Breakdown**: Automatically categorizes cleared steeples into Challenging, Intense, and Remorseless tiers.
* 🏆 **Hardest Tower Metric**: Instantly isolates and flags your single highest difficulty accomplishment.
